# Release notes - v0.9.0-beta.1

**Playwright Run Diff** - compare two independent Playwright trace runs, locate behavioral regressions, and share a reproducible, privacy-aware diff report. All processing is local; trace bytes are never uploaded.

This is the first public beta. Feedback via GitHub issues is welcome.

## Highlights

- **Browser explorer (SPA)**: drop two trace zips, get an aligned action-by-action diff. Dashboard, action alignment, network/console diffs, visual diff with slider/blink/diff-only modes and interactive ignore masks, manual pair/unpair, saved-report reopen, dark/light themes. Runs fully in a Web Worker - no uploads.
- **`run-diff` CLI** (`@sanestly/run-diff`): `compare` / `inspect`, JSON + Markdown + self-contained HTML reports, `--fail-on` CI thresholds with exit codes 0/1/2/3, multi-run aggregate statistics, `--config`, `--before-run/--after-run` stream selection.
- **Real trace support**: verified against `browserContext.tracing` on Playwright 1.60.0 and 1.64.1, and `@playwright/test` (`use: { trace: 'on' }`) - on Chromium, Firefox and WebKit. Multi-stream test-runner archives expose selectable runs; assertions detected via `method:"expect"`.
- **Privacy**: sanitized reports redact tokens/headers/cookies, never embed screenshots or DOM snapshots, ship strict CSP (`default-src 'none'`). Verified: zero external requests during a full browser session.

## Verified evidence

- 55 unit/golden tests, typecheck + lint clean
- Browser E2E PASS on Chromium, Firefox and WebKit
- Benchmark: 110 MiB archive (40k actions) parses in ~0.4s, compares in ~4.2s; 400 MiB archive rejected before inflate
- `pnpm pack` artifacts verified and installed cleanly in a fresh directory

## Known limitations

- `browserContext.tracing` does not record assertions or `test.step` - reported as "not recorded" (test-runner traces do).
- A single recording is not statistical proof of regression; multi-run aggregates are directional (medians/p90 only with n>=10).
- Archives are inflated into memory once (bounded: 150 MiB compressed default, 600 MiB uncompressed aggregate) - no streaming mode.
- Screenshots are screencast JPEG frames; diffs under ~2% may be compression noise and are reported at `info` severity.
- Screenshot *content* is never modified - credentials visible inside a screenshot are not detectable.
- Firefox/WebKit traces parse correctly but are only fixture-tested at Playwright 1.64.1.
- Non-JS SDK producers are untested (tolerant fallback adapter labels them `partial`).
